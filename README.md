# Sunflower Dream 🌻

A full-screen interactive animated sunflower garden. Botanically inspired realistic sunflowers bloom upwards and sway naturally under a starry night sky. After the flowers bloom, **10th October** appears in glowing typography, followed by **When it all began !!**.

Clicking any sunflower anywhere in the field opens the song:
[JP Saxe - If the World Was Ending ft. Julia Michaels](https://youtu.be/1jO2wSpAoxA?si=Ans21XcQZF4w-LBF)

## Preview Locally
Open `index.html` directly in any web browser, or serve with any static server.

## Deploy
This is a pure vanilla HTML/CSS/SVG project with zero dependencies. It can be deployed directly to GitHub Pages, Vercel, Netlify, or Cloudflare Pages.
